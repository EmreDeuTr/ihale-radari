# İhale Radarı

Almanya kamu ihalelerini (oeffentlichevergabe.de + TED) her sabah tarar, Radevormwald çevresindeki
peyzaj/GaLaBau ihalelerini süzer ve `docs/` altında web sayfası + Excel yayınlar.

- Ayarlar: `config.json` (merkez, km, CPV kodları, anahtar kelimeler) – GitHub'da kalem ikonuyla düzenlenebilir.
- Elle çalıştırma: Actions → "Ihale taramasi" → Run workflow.
